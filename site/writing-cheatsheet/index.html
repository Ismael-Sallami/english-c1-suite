T2Essay (argumentativo)

40Intro: contexto + parafrasea la pregunta + tesis clara.

70Argumento 1 + fuente (Text A) + tu ejemplo.

70Contraargumento + fuente (Text B) → refútalo o matízalo.

40Tu idea propia / matiz + Text C.

30Conclusión: postura + condición o recomendación. Nada nuevo.

“To what extent do you agree?” → postura matizada: “…largely agree, provided that…”

T2Esqueleto de essay listo para rellenar

¶1 Whether [tema] has become a matter of considerable debate. While some maintain that [A], others contend that [B]. This essay will argue that [tesis], provided that [condición].

¶2 One compelling argument in favour of [X] is that… As the writer of Text A points out, [parafraseo]. A case in point is [ejemplo].

¶3 On the other hand, Text B warns that… Admittedly, … Nevertheless, [refutación].

¶4 What is often overlooked, however, is [idea propia]. This view is echoed in Text C, which…

¶5 On balance, [postura]. Only by [-ing] can we [resultado].

T2Report (informe)

10Título: Report on… + destinatario si lo hay.

351. Introduction: objetivo + en qué se basa.

702. Benefits / Findings (Text A + C).

653. Challenges / Concerns (Text B).

704. Recommendations: 2–3 medidas concretas (pueden ir en viñetas) + conclusión.

Usa encabezados. Tono impersonal (pasiva, it is recommended). Las viñetas solo en recomendaciones.

T2Frases para la introducción

Essay · contexto

  • Whether X should Y has become a matter of considerable debate.
  • It is often argued that…, yet this view overlooks…
  • Few would dispute that…; what remains unclear is…
  • In recent years, there has been growing concern about…

Essay · tesis

  • This essay will argue that…
  • While there are clear advantages, I firmly believe that…
  • I largely agree with this statement, provided that…

Report

  • The aim of this report is to assess whether…
  • This report examines… and makes recommendations on…
  • It draws on three sources: …

T2Abrir cada párrafo

Argumento

  • One compelling argument in favour of… is that…
  • Perhaps the most significant benefit is…
  • A further consideration is…

Contraargumento

  • On the other hand, critics point out that…
  • That said, it would be naive to ignore…
  • Opponents of this view contend that…

Conceder → refutar

  • Admittedly, … Nevertheless, …
  • While this may be true to some extent, …
  • This argument, however, fails to take into account…

Ejemplo / prueba

  • A case in point is…
  • This is clearly illustrated by…

Report · secciones

  • The evidence suggests that…
  • A major drawback, however, is…
  • Particular attention should be paid to…

T2Citar las fuentes sin copiar

  • According to Text A, …
  • As the writer of Text B points out / warns, …
  • Text C highlights / illustrates the fact that…
  • This view is echoed in Text C, which…
  • Both texts agree that…, whereas Text B…
  • In contrast to Text A, Text B suggests that…
  • Drawing on Text A, it could be argued that…

Verbos para referir

argueclaimmaintaincontendacknowledgeemphasisewarnnotesuggestquestion

Parafrasear: 4 trucos

  • Sinónimos: costly → expensive
  • Cambiar la categoría de la palabra: reduce → a reduction in
  • Activa ↔ pasiva
  • Reordenar: empieza por la consecuencia

Usa todas las fuentes: ignorar una te baja de banda. Combínalas (“Both texts…”).

T2Conclusión y recomendaciones

Conclusión

  • All things considered, …
  • On balance, the advantages outweigh the drawbacks, provided that…
  • In light of the above, it seems clear that…
  • Ultimately, the key lies in…

Recomendar (report)

  • It is recommended that the council (should) introduce… (subjuntivo: sin -s)
  • The council would be well advised to…
  • Priority should be given to…
  • A more effective approach would be to…
  • Steps should be taken to ensure that…
